# Contributing

Thanks for considering a contribution to this project.

## License

This project is licensed under the [Apache License, Version 2.0](./LICENSE).

If you're contributing as an individual, on your own behalf, Section 5 of the
Apache License already covers it: any contribution you submit is automatically
licensed under the same terms as the project, with no extra paperwork needed.

**If you're contributing on behalf of an employer** (for example, your
company uses Incredibuild and you're submitting a fix or feature as part of
your job), your employer needs to sign our Corporate Contributor License
Agreement (CCLA) before the contribution can be merged. This confirms your
employer agrees the contribution is released under this project's license.

> **Status: pending.** The CCLA for this project has not been finalized yet.
> Once it is, this section will be updated with the document and instructions
> for signing it. Until then, please open an issue or contact the maintainers
> before submitting a corporate contribution.

## Getting started

1. Fork the repository and create a branch for your change.
2. Make your change, following the existing code style.
3. Open a pull request describing what changed and why.
